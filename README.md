# WorkshopHub – לקוח React

לקוח מינימלי שמדגים את השרת (`WorkshopHub`, ב-repository נפרד) מקצה לקצה.
העיצוב והמבנה פשוטים בכוונה – כל הלוגיקה וההרשאות נמצאות בשרת.

## הרצה

דרוש Node.js 18 ומעלה, והשרת צריך לרוץ על `http://localhost:5080`.

```bash
npm install
npm run dev
```

הלקוח עולה על `http://localhost:5173` (זו הכתובת שהשרת מאשר ב-CORS), ופונה ישירות לשרת.
אם השרת רץ בכתובת אחרת: להעתיק את `.env.example` ל-`.env` ולעדכן את `VITE_API_URL`.

## בנייה לאתר המפורסם

```bash
npm run build:site
```

הפקודה בונה את הלקוח לתיקייה `dist` כך שהוא פונה לאותה כתובת שממנה נטען. את תוכן `dist` מעתיקים לתיקייה `WorkshopHub.API/wwwroot` בשרת, והשרת מגיש את הלקוח וה-API מאותה כתובת.

## המסכים

1. **התחברות והרשמה** (`src/pages/AuthPage.jsx`) – ה-JWT נשמר ב-localStorage ונשלח ב-header‏ `Authorization: Bearer` בכל בקשה (`src/api.js`).
2. **רשימת מפגשים** (`src/pages/SessionsPage.jsx`) – עם סינון ו-pagination אמיתי מול השרת: הלקוח מבקש עמוד אחד בכל פעם (`page`, ‏`pageSize`).
3. **הפעולה על המשאב המוגבל** – כפתור "הרשמה" בכל מפגש (ו"הצטרפות לרשימת ההמתנה" כשהמפגש מלא), וביטול הרשמה. מסך "ההרשמות שלי" (`src/pages/MyRegistrationsPage.jsx`).
4. **הצגת 409** (`src/components/ErrorNotice.jsx`) – כשהשרת מחזיר 409 מוצגת הודעה בולטת שמסבירה מה קרה (המקום נתפס / המפגש מלא), הרשימה נטענת מחדש עם המצב העדכני, ומוצעת הפעולה הבאה (להצטרף לרשימת ההמתנה או לנסות שוב).

## איך לראות 409 בפועל

1. לפתוח את הלקוח בשני חלונות (אחד מהם בחלון פרטי), ולהתחבר בכל אחד כמשתתפת אחרת – למשל `rachel@workshophub.local` ו-`leah@workshophub.local`, סיסמה `Member#2026!`.
2. בשני החלונות מוצג המפגש "יסודות Excel למשרד" עם **מקום אחרון**.
3. ללחוץ "הרשמה" בחלון הראשון – ההרשמה מצליחה.
4. ללחוץ "הרשמה" בחלון השני, **בלי לרענן** – המסך עדיין מציג מקום פנוי, אבל השרת מחזיר 409, ומוצגת ההודעה שהמפגש כבר מלא יחד עם כפתור להצטרפות לרשימת ההמתנה.

למנהלת (`admin@workshophub.local` / `Admin#2026!`) מוצג גם "שינוי מספר המקומות". העדכון נשלח עם ה-`rowVersion` שנטען עם הרשימה, ואם מישהי נרשמה למפגש בינתיים – השרת מחזיר 409 במקום לדרוס את השינוי.

התחרות האמיתית (כמה בקשות באותה מילישנייה) מודגמת בסקריפט `scripts/race-demo.mjs` שב-repository של השרת.
